# 🚀 Kanban Board

A responsive and interactive Kanban Board web application built using HTML, CSS, and JavaScript.

---

# 📖 Overview

Kanban Board helps users organize tasks visually using a drag-and-drop workflow system with three columns:

- 📝 To Do
- ⚡ Doing
- ✅ Done

Users can create, edit, delete, search, and move tasks dynamically between columns. The application stores task data using localStorage so tasks remain saved even after refreshing the browser.

The project also includes:
- 🌙 Dark/Light Mode
- 📅 Due Dates
- 🎯 Priority Labels
- 🔍 Task Search
- ✨ Smooth Animations
- 📱 Responsive Design
